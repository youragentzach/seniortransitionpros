# seniortransitionpros.com

The Senior Transition Pros website, served by GitHub Pages from `main` and built with Jekyll.

**Agents and contributors: read [AGENTS.md](AGENTS.md) before changing anything.** It covers
who owns which files, the facts that are settled, the content rules, and how changes go live.

## Layout of the repo

| Path | What it is |
| --- | --- |
| `index.html` | Landing page with the family intake and provider claim forms. No front matter, so Jekyll copies it unchanged |
| `guide-cleanout-parents-house-atlanta.html` | The original cleanout guide. No front matter; the URL stays as is |
| `guides/index.html` | The guides index at /guides/ |
| `_posts/` | Published guides, served at /guides/guide-name/ |
| `_drafts/` | Guides in progress. Never published |
| `_layouts/`, `_includes/`, `assets/css/site.css` | Shared templates and styles |
| `about.md`, `how-we-make-money.md`, `how-we-verify.md`, `how-we-write-our-guides.md`, `privacy.md`, `contact.md` | Trust pages |
| `_config.yml` | Jekyll and plugin settings |
